# Lexel Brand Assets

Official Lexel mark and size guidance. Do not recolor, stretch, crop, rotate, or add effects to the mark.

## Files

| File | Use |
| :--- | :--- |
| `lexel-logo.svg` | Primary full-color mark for headers, README, and marketing |
| `lexel-logo.png` | 800 px transparent fallback |
| `lexel-icon.svg` | Square app icon, 512 px viewBox |
| `lexel-icon-1024.png` | Desktop and store icon source |
| `lexel-icon-*.png` | Pre-rendered 16, 32, 48, 64, 128, 180, 192, 256, 512 px icons |
| `favicon.ico` | Multi-size browser favicon |

## Rendered Sizes

| Surface | Asset | Height |
| :--- | :--- | ---: |
| Web header | `lexel-logo.svg` | 32 px |
| Web footer | `lexel-logo.svg` | 24 px |
| Desktop header | `lexel-logo.svg` | 24 px |
| Browser popup header | `lexel-logo.svg` | 24 px |
| Browser side panel header | `lexel-logo.svg` | 24 px |
| Browser options header | `lexel-logo.svg` | 32 px |
| Floating panel header | `lexel-logo.svg` | 20 px |
| Inline pills and popovers | `lexel-logo.svg` | 16 px |
| README | `lexel-logo.svg` | 180 px wide |
| Browser favicon | `favicon.ico`, `icon-16.png`, `icon-32.png` | 16, 32 px |
| Web app icon | `icon-192.png`, `icon-512.png` | 192, 512 px |
| Apple touch icon | `apple-touch-icon.png` | 180 px |
| Desktop app icon | `lexel-icon-1024.png` | 1024 px source |
| VS Code extension icon | `icon.png` | 128 px |

The primary mark has an 845:715 aspect ratio. Always use `height` plus `width: auto` so the mark never distorts.

## Clear Space

Keep clear space equal to at least 25 percent of the mark height on every side. Do not place text or controls inside that space.

## Minimum Size

Use the full mark at 16 px height or larger. Use the square app icon at 16 px or larger.
